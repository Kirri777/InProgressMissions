# In Progress Missions

Shows all in-progress garrison missions across your alts directly in the garrison report tab, with a minimap button for quick access.

Personal fork of [IPM on CurseForge](https://www.curseforge.com/wow/addons/ipm).

## Midnight Ready

Compatible with World of Warcraft: Midnight (retail). Uses current Blizzard APIs.

## Features

- **Alt mission tracking** — See missions from all your characters in one place
- **Blizzard garrison report integration** — Missions appear directly in the garrison report tab
- **Covenant mission improvements** — Enhanced layout, tooltips, and smooth scrolling for Shadowlands mission frame
- **Mission tooltips** — Hover for detailed mission info, follower abilities, and rewards
- **Right-click menu** — Sort options, ignore profiles, toggle mission types
- **Minimap button** — Left-click to toggle the garrison page, right-click for settings
- **Settings panel** — Toggle minimap button visibility via Esc → Options → AddOns

## Slash Commands

| Command | Description |
|---------|-------------|
| `/ipm` | Open garrison landing page (or list saved missions if no garrison) |
| `/inprogressmissions` | Same as `/ipm` |
